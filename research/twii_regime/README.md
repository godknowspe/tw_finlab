# 台股大盤多空規則研究

回答一個問題：簡單的趨勢規則在 `^TWII` 上是否有用？獨立於儀表板，只讀不寫，不碰帳本。

```bash
PYTHONPATH=. .venv/bin/python -m research.twii_regime.run --refresh   # 重抓並凍結資料，再跑研究
PYTHONPATH=. .venv/bin/python -m research.twii_regime.run             # 用 snapshot/ 的凍結資料重跑
PYTHONPATH=. .venv/bin/python -m research.twii_regime.report          # 產生自包含的 report.html
```

`report.html` 內嵌圖表函式庫與資料，直接開檔即可（瀏覽器若封鎖 `file:`，用 `python3 -m http.server --bind 127.0.0.1`）。
`results.json`、`report.html` 可由指令重新產生，已列入 `.gitignore`；`snapshot/` 是凍結資料，納入版本控制以便重現。

## 設計重點

- 收盤出訊號、**隔日開盤成交**。買進前的隔夜跳空不算賺，賣出前的跳空照賠（`engine.py` 有逐項測試）。
- 兩個實驗，**不互相比較排名**：機制實驗（`^TWII` 價格指數，1999 起，涵蓋 2000、2008 兩次大跌）；投資實驗（`^TWII` 出訊號、交易 0050，含息含成本，2014 起，因為 Yahoo 的 0050 股息從 2013 年才有紀錄）。
- 所有參數用慣例值固定（200/50/252 日、20 日波動、目標 10%），**沒有搜尋最佳化**。150/200/250 日只做穩定性檢查。
- 勝率只算「空手→持有→空手」的完整回合；買進持有與不歸零的波動目標沒有完整回合，顯示 N/A。勝率要與盈虧比、年化、最大回撤一起看。
- 統計不確定性：對所有策略同一批交易日抽區塊（120 日）做 bootstrap，報與買進持有的差距區間。它只衡量「這段歷史樣本留下多大的不確定」，不是新行情，也不是未來回撤的上限。
- 前後半段比較只是探索：整段樣本已被看過，不能當作乾淨的樣本外驗證。

## 資料注意

- 0050：2014-01-02 有 1:4 分割，Yahoo 的原始 `Close` 沒還原，`data.py` 自行還原 OHLC、量與股息的股份單位。
- Yahoo 的 0050 在 2014-07-23、2016-07-08、2025-06-11 至 06-17 缺資料（`^TWII` 當天有正常 K 線）；那幾天沒有成交價，訊號延到下一個有價日成交。
- `^TWII` 為價格指數，不含股息；沒有可用的加權報酬指數，所以機制實驗不可直接交易。
- 現有儀表板的 `src/domain/regime.py` 規則（策略 F）原樣凍結，未為這次研究修改。
