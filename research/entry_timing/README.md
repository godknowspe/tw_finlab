# 還沒投入的錢：一次買滿、分批、還是等回撤？

延續 `research/twii_regime`，共用它凍結的資料（0050 含息總報酬、^TWII 價格）。獨立於儀表板。

```bash
PYTHONPATH=. .venv/bin/python -m research.entry_timing.run      # 算策略網格 -> results.json
PYTHONPATH=. .venv/bin/python -m research.entry_timing.report   # 產生自包含的 report.html
```

## 方法

- 每個起點日（每 5 個交易日一個）有 1.0 的現金，視窗結束日估值，與「起點一次買滿」比期末財富。
- 策略：分 3/6/12 個月平均買；先買 0/50/70%，其餘分 2~3 檔，每跌 5/10/15/20/30%（自視窗起點以來的最高價算）加碼；可選「12 個月後強制投入」。未觸發的檔位維持現金，現金利率 0% 或 1%。
- 無交易成本。

## 讀的時候要小心

- 視窗互相重疊，視窗數不是證據數：0050 的 3、5 年持有期只相當於約 4、3 段獨立歷史，而且全部視窗期末都上漲，「等回撤」的好處根本沒機會被測到。
- `^TWII` 含 2000、2008 兩次大跌，但也只有約 2 次獨立的熊市。
- 網格有 5 個間距 × 2 個檔數 × 3 個先買比例；挑「看起來最好的一格」有多重比較偏差。
- 「上漲／下跌視窗」是事後依期末價格分的，事先無法知道自己落在哪一種。
